# 远程连接手动测试条目

自动化无法覆盖的场景（真实 PTY、真机浏览器、网络切换）。遵循 `docs/测试编写原则.md`，仅记录无法自动化的部分。

> UI 统一化后浏览器端即主应用 UI（TokenGate 认证门 + 完整视图流），下述"手机端/远程端"均指同一套 UI 在浏览器中的表现。

## U UI 统一化（宽屏浏览器 + 手机浏览器）

### U-1 手机宽度整体走查（≤768px）

- **目标**：主 UI 手机断点全流程可用
- **前置**：远程已开启，手机浏览器经 token/配对码连接
- **步骤**：项目页 → 展开近期会话折叠段 → 进入项目 → 新建会话 → 终端输入 → 底部栏开侧边栏抽屉 → 开设置（顶部 tab）
- **预期**：
  - 图标栏变为底部横栏（不遮挡终端，safe-area 生效）
  - 侧边栏为全宽抽屉 + 遮罩，点遮罩关闭
  - 设置页导航为顶部横向滚动 tab
  - 终端字号为桌面设置的 0.75 倍，软键盘弹出时终端自动 fit 不被遮挡

### U-2 桌面/宽屏回归（>768px）

- **目标**：B 端改动不影响桌面布局
- **步骤**：同一账号在桌面 Tauri 与宽屏浏览器（≥1280px）分别走查主流程
- **预期**：图标栏在左侧、侧边栏为 flex 展开（无遮罩）、设置页为左竖导航、终端字号为设置原值

### U-3 真机软键盘

- **目标**：软键盘弹出/收起终端正常
- **步骤**：手机终端点输入区唤起软键盘，输入命令，收起键盘
- **预期**：弹出时 app 高度收缩、终端 fit（PTY resize）、内容不被键盘遮挡；收起后恢复

### U-4 远程开启端口冲突报错

- **目标**：8747 被另一 CC-Box 实例占用时，开启远程给出可读错误（而非仅"开启失败"）
- **前置**：实例 A 已开启远程（监听 8747）；再启动实例 B
- **步骤**：实例 B 打开远程访问面板（触发自动开启）
- **预期**：面板显示含 "failed to bind port 8747" 的错误文案；关闭实例 A 后在实例 B 重开面板可正常显示二维码

### U-5 快捷键工具条（手机断点）

- **目标**：软键盘按不出的控制键可用按钮补齐
- **步骤**：手机进入终端会话，点工具条各键：⇧Tab（切换工作模式）、Ctrl+J（输入多行后一次提交）、Esc、^C、↑↓（历史）
- **预期**：⇧Tab 循环切换 auto-accept/plan 模式指示；Ctrl+J 在输入框插入换行不提交；↑↓ 翻历史命令；宽屏浏览器与桌面 Tauri 不显示工具条

### U-6 多实例宿主制

- **目标**：多 CC-Box 实例并存时远程不冲突、中继不互踢
- **步骤**：
  1. 实例 A 开启远程（成为宿主，占 8747），手机扫码连接
  2. 启动实例 B，打开远程面板
  3. 关闭实例 A，实例 B 重新打开远程面板
- **预期**：
  - B 面板显示"远程服务由本机另一 CC-Box 实例提供"+ 可扫码的局域 URL（与 A 相同、token 共享），无停止按钮；B 不连中继（日志无 relay registered）
  - A 关闭后 B 重开面板可正常开启并成为新宿主，手机重连即可用

### U-7 断开重开踢掉旧客户端（安全阻断）

- **目标**：二维码/配对泄露后，「停止远程→重新开启」使一切旧凭证失效
- **步骤**：
  1. 手机 A、手机 B 均完成配对/扫码连接
  2. 桌面点「停止远程访问」→「开启远程访问」
  3. 面板出现**新**局域码与新配对码（日志 `token rotated` / `device identity rotated`）
  4. 手机 A/B 用旧凭证尝试连接；用新码重新扫码
- **预期**：旧局域 URL 认证失败；旧 access_token 连中继无响应/被拒（指向已废弃 device_id）；新码扫码后正常使用——包括用户自己的手机也需要重扫

### U-8 远程互抢遮罩与接管回来（远程-远程）

- **目标**：远程端 A 被另一远程端 B 抢走会话时，A 显示遮罩（非断流），可随时抢回
- **步骤**：
  1. 两个浏览器（手机 A / 手机 B 或两个浏览器 tab）连同一桌面，A 打开某会话
  2. B 打开同一会话（attach 抢占）
  3. 观察 A：出现「此终端已在远程端接管」遮罩；遮罩期间桌面 CLI 持续输出
  4. A 点遮罩上的「接管回来」
- **预期**：A 遮罩解除、恢复控制权与最新内容（订阅保留期间数据层持续同步，无内容缺失/重复）；B 转为显示遮罩（互抢对称）；桌面端同场景显示相同遮罩

### U-9 刷新/新设备恢复运行中会话

- **目标**：浏览器 Tabs 是内存态，刷新或新设备连接后能回到运行中的会话
- **步骤**：
  1. 手机端打开某项目的运行中会话，刷新页面（或用另一设备连接）
  2. 项目列表：该项目按钮显示运行数徽标；近期会话出现该会话（now/运行中圆点）
  3. 点进项目
- **预期**：Tabs 自动恢复；进入项目后终端自动 attach（从桌面接管时桌面出遮罩）并显示 tail 内容；此前未点击的会话不自动抢占（独占语义）

## R1 局域网只读

### R1-1 手机访问会话列表与输出

- **目标**：手机浏览器通过直连 URL 看到会话状态与终端输出
- **前置**：桌面端 CC-Box 打开任一项目并启动 Claude 会话；手机与电脑同一 Wi-Fi
- **步骤**：
  1. 桌面 设置 → 远程 → 开启，复制手机访问地址
  2. 手机浏览器粘贴地址打开
- **预期**：
  - 页面自动通过 URL fragment 中的 token 完成认证，无需手动输入
  - 项目页显示该项目（运行中会话数徽标），近期会话含该会话
  - 进入项目可 attach 查看终端完整渲染（ANSI 正常）
  - 桌面端操作产生新输出时，手机实时追加

### R1-2 working/pending 状态圆点

- **目标**：hook 状态机在手机端正确呈现
- **前置**：R1-1 连接正常
- **步骤**：桌面端会话内发送一条 prompt
- **预期**：
  - Claude 工作期间手机列表圆点为绿色闪烁（working）
  - 完成等待输入时变为黄色（待处理）
  - 会话退出后从列表移除，若正在查看则显示"会话已结束"

### R1-3 断线重连

- **目标**：Wi-Fi 切换/后台切回后自动恢复
- **前置**：手机已连接并停留在输出视图
- **步骤**：手机开飞行模式 10 秒后关闭；或将手机浏览器切后台 1 分钟后切回
- **预期**：
  - 顶栏短暂显示"重连中…"
  - 网络恢复后自动重连，列表与输出视图恢复，期间桌面输出经 tail 补齐

### R1-4 token 认证安全

- **目标**：错误 token 被拒绝且不再重试
- **前置**：远程已开启
- **步骤**：手机浏览器访问 `http://<IP>:<端口>/`，手动输入错误 token
- **预期**：显示"令牌无效"，停止连接；输入正确 token 后正常进入

### R1-5 桌面重启后开关状态保持

- **目标**：配置持久化
- **步骤**：开启远程 → 完全退出并重启 CC-Box
- **预期**：远程服务器自动启动，token 不变（手机无需重新输 token）

### R1-6 端口占用回退

- **目标**：8747 被占用时不影响应用启动
- **步骤**：用其他程序占用 8747 端口后启动/开启远程
- **预期**：日志记录绑定失败，应用其余功能不受影响

## R2 交互与独占接管

### R2-1 手机接管与输入

- **前置**：R1-1 连接正常；桌面端有运行中的 Claude 会话
- **步骤**：手机列表点进会话 → 在手机 xterm 中输入一条 prompt 发送
- **预期**：
  - 点进后桌面该 Tab 出现"已在手机端接管"全遮罩
  - 手机 xterm 完整渲染（含颜色），软键盘可唤起并输入
  - Claude 响应实时显示在手机上

### R2-2 桌面接管回来

- **前置**：R2-1 手机持有中
- **步骤**：桌面点遮罩上的"接管回来"
- **预期**：
  - 桌面遮罩消失，终端尺寸恢复桌面 fit，接管期间内容零缺失
  - 手机显示"桌面已接管"横幅，提供"重新接管"
  - 期间手机再点"重新接管"可抢回，桌面再现遮罩

### R2-3 手机断连自动归还

- **步骤**：手机持有会话时开飞行模式 10 秒再关闭
- **预期**：桌面遮罩自动消失（断连即归还）；手机网络恢复后自动重连并重新接管

### R2-4 手机新建会话

- **步骤**：手机列表页点"＋ 新建会话" → 选项目 → 点"＋ 新建会话"
- **预期**：
  - 桌面自动出现新 Tab（绑定手机创建的 PTY）且显示被手机接管遮罩
  - 手机直接进入新会话终端可交互

### R2-4b 手机恢复历史会话

- **步骤**：手机"＋ 新建会话" → 选项目 → 历史列表中点某会话
- **预期**：
  - 恢复的会话带完整上下文（Claude 记得之前的对话）
  - 桌面新 Tab 名为 sessionId 前 8 位（hook sessionStart 后更新为正式名称），与桌面本地 resume 行为一致

### R2-5 手机关闭会话

- **步骤**：手机列表卡片点"×"确认关闭
- **预期**：桌面对应 Tab 走 pty-exit 清理流程（与本地关闭一致）；手机列表即时移除

## R3 公网中继

### R3-1 中继部署与接入

- **前置**：VPS 按 [deploy.md](deploy.md) 部署 cc-box-relay + nginx 子域 + 证书
- **步骤**：桌面远程弹窗 → 中继区填 `https://<中继域名>` → 连接
- **预期**：显示"中继已连接"与配对二维码（约 2s 内出现）

### R3-2 手机配对一次长期有效

- **步骤**：手机（任意网络）扫中继配对码
- **预期**：
  - 打开中继页面自动完成配对并进入会话列表
  - 关闭浏览器再开（含切 Wi-Fi/流量）打开即连，无需重新扫码
  - 中继重启后需重新配对（预期行为）

### R3-3 公网完整功能

- **目标**：中继模式下 R2 全部功能可用
- **步骤**：手机经中继接管会话、输入、新建、关闭
- **预期**：与局域网直连行为一致（同一套应用层 handler）
