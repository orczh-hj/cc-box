# CC-Box

## 概述

CC-Box 是运行 Claude Code 的桌面应用。它不改变 Claude Code 的能力——命令、快捷键、交互与终端中完全一致——改变的是使用它的方式。

目标是把操作路径缩短：在终端里要好几步完成的事，在这里尽量变成看得见的列表、开关和一次点击。几个典型场景：

- 换项目：不必先 `cd` 到目录
- 新建会话：常用参数存为预设，不必每次重复输入
- 切换 API：不必手动改配置
- 查看 MCP 服务器、skills、插件或会话状态：不必翻目录、记斜杠命令
- 离开电脑：电脑或手机浏览器直接接管会话

下文按这些场景说明具体操作。

应用不会改动 Claude Code 的配置（Provider 管理除外）。缺少 Claude Code、Windows 下的 Git 等环境时，应用内会提示并提供安装引导。

## 快速上手

1. 从[下载页](index.html#download)获取对应平台安装包并安装
2. 启动应用，在首页选择已有项目或添加项目目录
3. 会话内使用方式与终端相同（命令、快捷键见 Claude Code 部分）
4. 侧边栏管理会话、扩展与文件（MCP、Skills、插件）
5. 按需配置 Provider 与远程连接

## 项目管理

终端里切换项目要先进入对应目录。这里项目是一张卡片，所有项目并列可见。

- 添加项目：首页底部「添加项目」，选择本机目录；之后固定出现在列表中，不必再输入路径
- 项目卡片显示名称、路径与活跃会话数，点击进入该项目的工作区
- 隐藏项目：卡片右上角关闭图标；隐藏后不再展示，重新添加同一目录时恢复其历史会话
- 近期会话：首页左侧按时间列出各项目最近的会话，点击直接进入，不必先切目录再恢复会话
- 启动选项：首页与侧边栏底部的启动选项区
  - `允许 skip-permissions`：新建会话时跳过逐条权限确认（仅在可信环境使用）
  - 自定义参数：填写要附加的 CLI 参数（如 `--model sonnet`），之后新建会话自动带上
  - 「保存为默认」：按项目记住以上选项，省去每次重复输入

## 会话管理

每个会话是一个独立的终端标签，运行一次完整的 Claude Code 对话。

![项目内视图：左侧面板列出打开的标签页与历史会话（含状态与时间），右侧为当前会话终端](/screenshots/docs/terminal-sessions.png)

**会话操作**

| 操作 | 入口 | 说明 |
|------|------|------|
| 新建 | 侧边栏「新建」按钮 / `Alt+N` | 按当前启动选项新建一个会话 |
| 切换 | 点击标签或侧边栏条目 / `Alt+↑` `Alt+↓` | 切换后原会话继续运行，输出保留 |
| 重命名 | 侧边栏当前会话的铅笔图标 | 名称同步显示到远程端 |
| 重启 | 侧边栏「重启」按钮 / `Alt+R` | 关闭当前会话，并以相同项目和启动选项重新开始 |
| 关闭 | 标签关闭按钮 / 侧边栏 × | 关闭该会话 |

**状态指示**

- 每个会话条目带状态圆点：运行中 / 思考中 / 等待输入 / 已停止，随会话实时变化；不必逐个切进终端确认哪个在等待输入
- 有新动态的会话显示未读标记，打开后自动清除；状态同步到远程端
- 已停止的会话在支持恢复时显示重启按钮，可继续原对话

**会话面板（侧边栏「会话」）**

- 「打开的标签页」列出当前工作区的全部会话；「历史记录」列出该项目过往会话（带最后活跃时间）
- 顶部搜索框按名称过滤两类条目
- 多窗口远程模式下，标签按所属窗口分组显示

## 侧边栏面板

左侧工具条集中了会话、扩展与文件的入口。面板不遮罩终端、不抢占输入焦点，点击图标开合。

- **会话**：会话列表、状态与历史记录（见「会话管理」）
- **Skills**：浏览项目级与全局 skills
- **Agents**：浏览 subagents 定义
- **MCP**：已配置的 MCP 服务器与工具
- **插件**：已安装插件及其组件

Skills、Agents、MCP、插件四个面板用法一致：条目按来源分组，每项带启用开关；MCP 服务器可展开查看其中的工具。开关即时生效，原本需要编辑配置或移动文件，现在点一下即可；桌面端与远程端看到同一份状态。

![Agents 面板：按来源分组列出 subagents 定义](/screenshots/docs/agents-panel.png)

![MCP 面板：按「用户 / Plugin」分组列出服务器与传输方式，可展开查看工具](/screenshots/docs/mcp-panel.png)

工具条底部还有三个入口：

- **远程**：打开配对面板（见「远程连接」），仅桌面端显示
- **打开文件夹**：在系统文件管理器中打开当前项目目录，仅桌面端显示
- **设置**：打开设置（见「设置区」）

## 远程连接

终端只能在电脑前使用。远程连接把同一会话开放给浏览器：用电脑或手机浏览器打开桌面上的全部会话，查看终端、输入、处理审批，与坐在电脑前操作一致。功能默认关闭，按需开启。

![远程访问面板：显示配对二维码与访问链接、「局域访问」开关，以及更新连接码、刷新密钥、停止远程访问三个操作](/screenshots/docs/remote-panel.png)

**开启与配对**

1. 桌面：点击左侧工具条的二维码图标，或托盘菜单「远程连接」，打开远程面板
2. 首次点击「开启远程访问」，面板会给出配对二维码与访问链接
3. 默认使用公网模式，任何网络下的电脑或手机浏览器扫码、打开链接即可配对
4. 按需勾选「局域访问」改用局域网地址配对（见下）

**局域访问**

- 含义：配对链接改用电脑的局域网地址，流量只在局域网内传输，不经过公网服务器，外网无法访问
- 前提：访问设备与主机须在同一 Wi-Fi / 局域网；跨网络时无法打开该地址
- 取消勾选即恢复公网模式：无需在路由器上做端口映射，其他网络下也能访问
- 两种模式的访问地址不同，切换后需用面板给出的新链接重新配对

**三个操作**

| 操作 | 说明 |
|------|------|
| 更新连接码 | 配对码一次性、5 分钟有效，过期后自动换新；点击立即换出新码，旧码随即作废 |
| 刷新密钥 | 二次确认后，所有已配对的设备立即失效，需重新扫码才能连接 |
| 停止远程访问 | 关闭远程服务，所有设备断开连接；应用与后台运行不受影响，再次开启即恢复 |

**安全逻辑**

- 默认关闭；只有扫码配对过的设备可以访问，每台设备单独配对、可单独停用
- 局域网模式流量不出内网；公网模式流量加密后经中继服务器转发，服务器不解析内容
- 失效即时生效：刷新密钥后所有旧设备立即失去访问权；停止远程访问会断开一切连接
- 文件下载链接 10 分钟内有效、用后即失效；远程操作记录可在 `~/.cc-box/logs` 查看

**远程可用功能**

- **终端**：实时同步输出与输入；审批请求（权限确认）直接在浏览器中处理
- **会话**：新建 / 关闭 / 重启 / 重命名；会话按桌面窗口分组；桌面窗口全部关闭时可直接新建窗口
- **侧边栏**：Skills、Agents、MCP、插件面板均可浏览与开关，与桌面端状态一致
- **文件（文件面板）**：双向传输——上传设备上的文件到当前项目下的 `.cc-box-files/` 目录并自动在终端插入路径；桌面文件以 10 分钟内有效的链接下载，微信、系统浏览器均可
- **手机**：底部工具条提供 Esc、方向键等常用按键与软键盘开关；「选择复制」进入文本选取模式
- **输入权**：同一时刻每个会话只有一个设备可输入，多设备可同时操作不同会话；被接管的设备会收到提示，不会被断开

## Provider 管理

终端里切换 API 通常要改环境变量或替换配置文件。这里每个 Provider 是一个条目，点击「使用」即可切换。

入口：设置 → 接口。

![设置 → 接口：Provider 列表支持拖拽排序，每项提供使用 / 编辑 / 测试 / 删除操作，当前生效项标记「使用中」](/screenshots/docs/provider-panel.png)

- 新增：内置 50+ 厂商预设模板，选择模板填入密钥即可；也可完全自定义
- 导入：一键从 cc-switch 导入现有配置
- 通用配置：多个 Provider 共用的设置（如代理）单独维护，激活时自动一并生效
- 使用：点击「使用」激活该项；只把该 Provider 的接口配置保存进 Claude Code 设置，不影响其他设置——这是应用唯一改动 Claude Code 配置的地方
- 测试：对单项配置发起连通性测试，无需激活
- 排序：拖拽调整列表顺序

## 设置区

入口：左侧工具条齿轮图标，或 `Ctrl+,`。设置以标签页组织：

| 分区 | 内容 |
|------|------|
| 外观 | 终端字体大小（10–24px）、浅色 / 深色主题、界面语言（中 / 英） |
| 启动 | 开机自启动开关（开机后后台运行，不打开窗口） |
| 接口 | Provider 管理（见上一节） |
| 快捷键 | 应用快捷键清单 |
| 更新 | 检查更新、下载并安装；有新版本时托盘图标显示红点 |
| 关于 | 版本号、官网、代码仓库与 Claude Code 文档链接 |

**应用级快捷键**（终端内快捷键由 CLI 本身处理，不受影响）

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+,` | 打开设置 |
| `Alt+N` / `Alt+R` | 新建会话 / 重启会话 |
| `Alt+↑` / `Alt+↓` | 切换标签 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 增大 / 缩小 / 重置字体 |
| `Ctrl+Shift+H` | 回到项目列表 |
| `Ctrl+Shift+N` | 新建窗口 |
| `Ctrl+Shift+T` | 窗口置顶 |
| `Ctrl+Shift+←` / `Ctrl+Shift+→` | 窗口吸附到左 / 右半屏 |
| `Ctrl+Shift+R` | 重启应用 |

窗口顶部标题栏同时提供置顶与半屏吸附按钮，可用于把 CC-Box 与其他窗口并排摆放。

## 托盘与多窗口

Windows 与 macOS 上，应用由一个常驻后台的服务统一管理：关闭所有窗口后它继续运行，托盘图标保留，远程连接不中断；再次打开应用复用同一个后台服务，不会重复启动。

**托盘菜单**（从上到下）

| 菜单项 | 作用 |
|--------|------|
| 更新到 vX.Y.Z | 仅在有新版本时出现；点击打开窗口并跳到 设置 → 更新 |
| 各窗口名称 | 每个打开的窗口是一个菜单项，单击即显示并聚焦；同名窗口带序号；没有窗口时显示「暂无窗口」 |
| 开机自启动 | 勾选开关；开机后只启动后台服务，不打开窗口 |
| 新建窗口 | 打开一个新窗口，停在项目列表 |
| 远程连接 | 显示一个窗口并打开远程面板；没有窗口时先新建 |
| 刷新远程密钥 | 二次确认后，所有已配对设备立即失效 |
| 关闭 / 开启远程连接 | 随当前状态切换 |
| 退出 CC-Box | 确认后关闭所有窗口并退出后台服务 |

关闭远程连接、刷新远程密钥、退出 CC-Box 三项会先弹系统确认框。有新版本时，托盘图标右上角显示红点。

**多窗口**

- 打开方式：`Ctrl+Shift+N`、托盘「新建窗口」，或手机端没有窗口时点「启动窗口」
- 每个窗口有独立的项目与会话，窗口之间互不影响
- 窗口标题随内容变化：打开项目时显示项目名，停在项目列表时显示 CC-Box；托盘菜单与远程端的分组使用同一名称
- 多个窗口共享同一个后台服务：远程连接开启一次，浏览器能看到全部窗口的会话，并按窗口分组
- 全部窗口关闭后后台服务继续运行，远程连接与手机端会话保持
- 最多同时打开 12 个窗口

Linux 版本没有系统托盘，以后台方式运行；窗口、远程连接与开机自启动在设置或远程面板中管理。
